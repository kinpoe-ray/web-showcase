ntn 是 Notion 官方 CLI，一行 npm i -g ntn@latest 即装（需 Node 22+ / npm 10+）。 认证走 ntn login 浏览器 OAuth，或设 NOTION_API_TOKEN 环境变量。 所有计划可用，Workers 需 Business / Enterprise。

认证 · ntn login / logout / whoami

  • ntn login — OAuth 浏览器授权登录
  • ntn logout — 登出当前 workspace
  • ntn whoami — 查看认证用户和 workspace
  • ntn doctor — 健康检查：版本、配置、token、API 连通性

页面 · ntn pages

  • ntn pages get <id> — 获取页面为 Markdown（含 frontmatter）
  • ntn pages create — 创建页面（stdin / $EDITOR / --content）
  • ntn pages update <id> — 更新页面内容
  • ntn pages trash <id> — 删除页面

数据库 · ntn datasources

  • ntn datasources query <id> — 查询（filter / limit / 分页）
  • ntn datasources resolve <db-id> — database ID → data source ID

API 代理 · ntn api

  • ntn api <path> — 调用任意 Notion REST API 端点
  • ntn api ls — 列出所有支持的端点（40+）
  • ntn api <path> --docs — 查看端点官方文档
  • 语法：path=value 字符串 · path:=json 类型化 · name==val query
  • 覆盖：blocks · comments · pages · databases · data_sources · file_uploads · views · users · search

文件上传 · ntn files

  • ntn files create < file.png — 从 stdin 上传
  • ntn files create --external-url <url> — 外部 URL 引用
  • ntn files get <id> — 查看文件信息
  • ntn files list — 列出所有上传

Workers · ntn workers

  • ntn workers new — 初始化项目 · deploy 部署 · list 列表
  • ntn workers exec — 执行能力 · env 环境变量 · oauth 连接
  • ntn workers webhooks — Webhook 管理 · runs 运行记录
  • ntn workers usage — AI credit 用量 · tui 交互式终端 UI

使用场景

  1. 脚本自动化 — bash / python 批量操作 Notion 数据
  2. AI Coding Agent — Claude Code 通过 CLI 直接读写 Notion
  3. CI/CD 集成 — 管道中自动创建 / 更新 Notion 页面
  4. Workers 开发 — 部署和调试 Notion serverless 函数
  5. 内容管道 — pages get → 处理 → pages update
  6. 快速查询 — 终端直接搜页面、查数据库

关键环境变量

  • NOTION_API_TOKEN — API token（覆盖 keychain）
  • NOTION_WORKSPACE_ID — 指定 workspace
  • NOTION_KEYRING=0 — 文件认证替代系统 keychain
  • NOTION_WORKERS_CONFIG_FILE — Workers 配置文件路径
